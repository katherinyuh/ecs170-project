Part D Parameter Experiments

3.2 Detailed Experimental Setups

We changed one setting at a time: 18 generation runs across RNN, LSTM and GRU, plus three classification GRU runs. Generation uses all 1,622 jokes (30,303 windows), learned 100d embeddings, hidden size 128, one layer, context 3, dropout 0.2 and 15 epochs. Classification uses fine-tuned GloVe 100d, hidden size 128, one layer, 200-token reviews, dropout 0.3 and three epochs. Adam, learning rate 0.001, batch 64, clipping 5 and seed 2 are shared; recurrent dropout is zero.

Classification keeps 22,500 training reviews and 2,500 stratified validation reviews; the original 25,000-review test set is scored after the final epoch. Compare variants to this rerun baseline, since Part B trained on all 25,000 training reviews.

3.7 Ablation Studies

Hidden size 256 gave the strongest generation fit: RNN 65.70%, LSTM 70.88% and GRU 74.96%. The smaller embedding and lower learning rate reduced generation accuracy; depth and context changes had mixed effects. For classification, hidden size 256 changed test accuracy by +1.27 points and learning rate 0.0005 by +0.17 points relative to the rerun baseline. Each model used one seed, so small differences do not establish a reliable advantage.

Higher generation accuracy did not ensure better text: baseline and wider GRU both copied the chicken/playground joke, while the wider model repeated periods after "two artists had an art contest". Saved examples include training-overlap checks. Part D runs used CPU; the Colab notebook supports optional CUDA runs, with no measured GPU speedup claimed.
